# tree-view

`index.html` demonstrates JSON tree rendering, mouse/modal-tip behavior, and local tree data from `tree.json`/`electronics.json`. `index2.html` is a chocolate-themed JSON/component page with `chocolate-styles.css` content. `process-order.php` accepts `quantity`, `name`, and `email` query values and returns a demo success JSON message; it does not persist an order or send mail.
