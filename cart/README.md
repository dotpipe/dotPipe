# cart

The cart examples are separate pages: `products.html` lists products, `product.html` shows a product, `cart.html` shows cart state, and `checkout.html` demonstrates validation and order submission. `items.json`, `cart.json`, and the product page data provide local content; `styles.css` supplies the page styling. `order.html` is an empty/placeholder route in the current checkout set, so do not treat it as a completed order-confirmation backend.
