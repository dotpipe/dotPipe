dotPipe Documentation

Attributes

id

Unique identifier for the pipe element.

form-class

Used for form handling. Selects elements to include in a form by their name and value.

Example: <tag form-class="myFormClass">

ajax

Specifies the AJAX call to be made.

Format: file.extension:insertTarget:countByEvent

Example: <element ajax="data.php:resultDiv:3;data2.php:resultTag:2">

file

Specifies the filename to download when used with the download class.

Example: <tag class="download" file="document.pdf">Download</a>

insert

Specifies the target ID where the AJAX response should be inserted.

Example: <element insert="targetDivId">

modal

Used for JSON file insertion.

Format: json1.json:insert1.insert2.insert3;..

Example: <element modal="template.json:header.main.footer;">

x-toggle

Used for toggling class values.

Format: id1:class1;id1:class2;id2:class2

Example: <element x-toggle="btn1:active;btn2:hidden;">

Classes

tree-view

Used to return the tree-view modala to its resting place in the DOMNode selected through insert="".

Example: <div class="tree-view" insert="treeContainer">

clear-node

Used to clear specified nodes.

Related attribute: insert (specifies nodes to clear)

Example: <button class="clear-node" insert="div1;div2;">Clear

redirect

Used to follow AJAX calls in POST or GET mode.

Example: <a class="redirect" ajax="process.php">Submit

modala-multi-last

Used for creating multi-ajax calls. Inserts as last child.

Format in ajax attribute: foo.bar:insertHere:x (x is max number of insertions)

Example: <div class="modala-multi-last" ajax="data.php:resultDiv:3">Load More

modala-multi-first

Used for creating multi-ajax calls. Inserts as first child.

Format in ajax attribute: foo.bar:insertHere:x (x is max number of insertions)

Example: <div class="modala-multi-last" ajax="data.php:resultDiv:3">Load More

Special Functions

pipes()

Initializes the dotPipe functionality on the page.

Usage: Call this function after the DOM is loaded to activate dotPipe features.

domcontentload()

Ensures that dotPipe functionality is initialized when the DOM content is fully loaded.

Usage: This function is typically called automatically, but can be manually invoked if needed.

Threading Control with x-toggle

The x-toggle attribute can be used to control threading functionality in dotPipe. It leverages setTimeout for efficient execution of multiple tasks.

Example usage:

<button x-toggle="threadControl:active">Toggle Thread</button>

In the dotPipe codebase, setTimeout is used instead of setInterval. This allows for:

  • More flexible execution of multiple tasks
  • Better control over timing and frequency of operations
  • Improved performance when dealing with multiple threads or asynchronous processes

The setTimeout approach enables developers to fine-tune the behavior of threaded operations, ensuring optimal performance and responsiveness in dotPipe applications.

AJAX Response Processing

dotPipe efficiently handles AJAX responses through a custom processing mechanism.

Key aspects of AJAX response handling:

  • Automatic parsing of JSON responses
  • Dynamic content insertion into specified DOM elements
  • Support for chained AJAX calls
  • Error handling and logging

Example usage:

<div id="resultContainer" ajax="data.php:resultContainer"></div>

The AJAX response from data.php will be automatically processed and inserted into the element with id "resultContainer".

Form Handling with form-class

dotPipe provides robust form handling capabilities through the 'form-class' attribute.

Key features of form handling:

  • Automatic collection of form data based on class selectors
  • Seamless integration with AJAX submissions
  • Support for custom validation before submission
  • Dynamic updating of form elements based on server responses

Example usage:

<tag form-class="myForm" ajax="process.php:resultDiv">
        <tag type="text" name="username" class="myForm">
        <tag type="submit" value="Submit">
    </form>

This form will automatically collect data from inputs with class "myForm" and submit it to process.php, updating the element with id "resultDiv" with the response.

Multi-AJAX Calls

The 'modala-multi-last' class enables multiple AJAX calls with a limit on insertions.

Example:

<tag class="modala-multi-last" ajax="data.php:resultDiv:3">Load More</div>

Query String Handling

The 'query' attribute allows for easy specification of query parameters for AJAX calls.

Example:

<tag ajax="data.php" query="id=123&type=user">Load User Data</div>

Dynamic Class Toggling

The 'x-toggle' attribute provides a way to dynamically toggle classes on elements.

Example:

<tag x-toggle="btn1:active;btn2:hidden">Toggle Classes</button>

File Download

dotPipe simplifies file downloads with the 'download' class and associated attributes.

Example:

<tag class="download" file="report.pdf" directory="/files/">Download Report</a>

Clear Node

The 'clear-node' class allows for easy clearing of specified DOM elements.

Example:

<tag class="clear-node" insert="div1;div2">Clear Content</button>

AJAX Redirect

The 'redirect' class enables following AJAX calls in POST or GET mode.

Example:

<tag class="redirect" ajax="process.php">Process and Redirect</a>

Modala Functionality

Modala is a powerful feature in dotPipe for creating and managing modal dialogs with dynamic content.

Key features of Modala:

  • Dynamic loading of JSON-based templates
  • Automatic positioning and styling of modal windows
  • Support for nested modals
  • Integration with AJAX for real-time content updates

Example usage:

<tag modal="template.json:modalContent">Open Modal</button>

This will open a modal dialog with content defined in template.json, inserted into an element with id "modalContent".

Tree-View Functionality

The tree-view feature in dotPipe enables the creation of expandable, hierarchical structures for data representation and navigation.

Key aspects of tree-view:

  • Dynamic generation of tree structures from JSON data
  • Collapsible and expandable nodes
  • Integration with AJAX for on-demand loading of sub-trees
  • Customizable styling and behavior

Example usage:

<tag class="tree-view" ajax="tree-data.json:treeContainer"></div>

This will create a tree-view structure based on the data in tree-data.json, rendered within the element with id "treeContainer".

JSON Structure

Modala JSON Format

Example structure for Modala JSON files:

All key names must be in lowercase:


{
    "label": "Root",
    "table": {
        "label": "Table",
        "sales": {
            "textcontent": "Sales",
            "td2": {
                "ajax": "./tree.json",
                "class": "sale-label tree-view",
                "id": "sales-tag",
                "insert": "sales-tag",
                "textcontent": "On Sale!",
                "style": "color: #666;"
            }
        }
    }
}
