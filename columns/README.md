# columns

`columns.html` demonstrates the refresh component with HTML targets, two simultaneous targets, JSON content, a 10-second auto-refresh, column refresh, and whole-page refresh. `index.html` and the `column*`/`content*` files are alternate page/content payloads; `data.json` is the JSON source; `styles.css` is local presentation. The `*-updated.html` files are the replacement states used by the buttons.
