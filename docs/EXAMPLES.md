# Example index

| Directory/file | Entry point | Demonstrates |
|---|---|---|
| `landing/` | `index.html` | Showcase prose, `modala`, AJAX examples, multi-part content, carousel markup. Some referenced assets are illustrative and should be checked before deployment. |
| `inline/` | `index.html` | Inline variables, increment/decrement, toggle, clamp, and sleep-style macros. |
| `API/` | `index.php` | Strict JSON loading from `arrow-area.json`. |
| `activeMenu/` | `index.php`, `getarrow.php` | JSON menu/arrow composition and PHP-generated page definitions. |
| `activeMenu/menu_pages/` | `collective.php` | Menu page payload assembly. |
| `addons/` | `chat-demo.html` | Browser-local chat UI, channel/session/queue/ownership helpers, and PHP session endpoints. |
| `carousel/` | `index.php` | JSON-driven image carousel using local images. |
| `cart/` | `cart.html`, `products.html`, `product.html`, `checkout.html` | Cart/product/checkout/order pages and JSON data. |
| `clock/` | `index.html` | JSON-rendered clock/output controls; includes a local example renderer. |
| `columns/` | `columns.html` | HTML/JSON refresh targets and column layout. |
| `csv-test/` | `products.html` | CSV loading, sorting, paging, and display. |
| `guitar/` | `index.php` | JSON page payload with local media and CSS. |
| `login/` | `index.html` | Login/registration component with local form pages. |
| `tree-view/` | `index.html`, `index2.html` | JSON tree/modal-tip rendering and chocolate/order UI. |
| `xi-demo/` | `index.php` | ELSN-style site with `api/`, `fragment/`, and `health/` endpoint directories. |
| `dashboard/` | `index.html`, `file-editor.html` | XI control panel and file editor. |

Each local README documents the files in that directory. Root-level `endpoint.php`, `crud.php`, `xi-server.php`, `xi.mjs`, `domPipe.js`, and the documentation HTML files are documented in the root and layer guides.
