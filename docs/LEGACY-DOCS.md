# Legacy HTML documentation

`Docs.html` and `documentation-Aug-8-2025.html` are older, browser-rendered reference pages shipped with the project. They contain useful examples of attributes, tags, classes, and component markup, but they predate the current XI, data-* mirroring, `xi` timer, XI, and file-editor work.

Use the Markdown documents in this directory as the current source of truth. Treat examples in the legacy pages as historical unless the current `domPipe.js` implementation and the runnable example agree. The repository validator does not execute the examples embedded in these HTML documents.
