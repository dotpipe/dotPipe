Introduction to DomPipe.js

DomPipe.js is a lightweight JavaScript library that enhances HTML with dynamic functionality through custom attributes, tags, and classes. It simplifies AJAX calls, content loading, and UI interactions without requiring complex JavaScript code.

Note: DomPipe.js automatically initializes when the DOM content is loaded. All tags with the pipe tag are processed automatically.

Attributes

id

All tags being used with DomPipe.js must have an 'id' attribute for proper functionality.

Example
<pipe id="myPipe" ajax="data.json" insert="resultDiv"></pipe>

insert

Specifies the target element ID where the AJAX response will be inserted.

Example
<pipe id="dataPipe" ajax="data.json" insert="resultContainer"></pipe>
Content from data.json will be inserted here

ajax

Specifies the URL to call. Can include optional parameters separated by colons.

Basic Usage
<pipe id="simplePipe" ajax="data.json" insert="resultDiv"></pipe>
With Parameters
<pipe id="paramPipe" ajax="data.php:resultDiv:countByEvent" query="event:click;" insert="resultDiv"></pipe>

query

Defines query parameters to be sent with the AJAX request. Format is "key:value;" pairs.

Example
<pipe id="queryPipe" ajax="search.php" query="term:javascript;limit:10;" insert="searchResults"></pipe>

turn

Creates a turn-based element routine. Cycles through elements with the specified class.

Example
<div id="turnExample" turn="slide-item" class="decrIndex" index="1">Next Slide</div> <div class="slide-item">Slide 1 Content</div> <div class="slide-item">Slide 2 Content</div> <div class="slide-item">Slide 3 Content</div>
Next Slide
Currently visible slide content

callback and callback-class

Specifies a JavaScript function to call after the AJAX request completes. The callback-class identifies elements whose values will be passed to the callback function.

Example
<pipe id="callbackPipe" callback="processData" callback-class="form-field" ajax="process.php" insert="resultDiv">Submit</pipe> <input type="text" name="name" class="form-field" value="John"> <input type="text" name="age" class="form-field" value="30"> <script> function processData(params) { console.log("Processing data:", params); // params will contain "John, 30" } </script>

modal

Loads JSON files and inserts their content into specified target elements.

Example
<pipe id="modalPipe" modal="template.json:header.main.footer">Load Template</pipe>
Load Template
Template content would be loaded here

file and directory

Used with the "download" class to specify a file to download and its directory.

Example
<button id="downloadBtn" class="download" file="report.pdf" directory="/documents/">Download Report</button>

set, get, and delete

Manipulate attributes of other elements.

Set Example
<button id="setBtn" set="targetDiv:style:color:red">Set Text Color</button> <div id="targetDiv">This text will change color</div>
This text will change color
Get Example
<div id="sourceDiv" data-value="Important information">Source</div> <button id="getBtn" get="sourceDiv:data-value:targetDiv">Get Value</button> <div id="targetDiv">Value will appear here</div>
Delete Example
<div id="deleteTarget" style="color: red;">This has red text</div> <button id="deleteBtn" delete="deleteTarget:style">Remove Style</button>

x-toggle

Toggles CSS classes on specified elements.

Example
<button id="toggleBtn" x-toggle="panel:visible;indicator:active">Toggle Panel</button> <div id="panel" class="panel">This panel will toggle visibility</div> <div id="indicator">Status indicator</div>
This panel will toggle visibility
Status indicator

tool-tip and modal-tip

Creates tooltips that appear on hover. tool-tip shows text, while modal-tip loads content from a file.

Tool-tip Example
<span id="helpText" class="mouse" tool-tip="This is helpful information;tooltip-1;tooltip;3000;100">Hover for help</span>
Hover for help This is helpful information
Modal-tip Example
<span id="advancedHelp" class="mouse" modal-tip="help.json;3000;100">Hover for advanced help</span>

copy

Copies the content of a specified element to the clipboard.

Example
<div id="codeSnippet">console.log("Hello World");</div> <button id="copyBtn" copy="codeSnippet">Copy Code</button>
console.log("Hello World");

remove

Removes specified elements from the DOM.

Example
<div id="notification">This is a notification</div> <button id="closeBtn" remove="notification">Close Notification</button>
This is a notification

display

Toggles the visibility of specified elements.

Example
<button id="toggleVisibility" display="hiddenContent">Toggle Content</button> <div id="hiddenContent" style="display: none;">This content is initially hidden</div>
This content is initially hidden

headers

Sets HTTP headers for AJAX requests.

Example
<pipe id="apiPipe" ajax="api/data" headers="Authorization:Bearer token123&Content-Type:application/json" insert="apiResult"></pipe>

mode

Sets the HTTP method for AJAX requests (GET or POST).

Example
<pipe id="postPipe" mode="POST" ajax="submit.php" query="name:John;age:30;" insert="resultDiv">Submit</pipe>

form-class

Specifies a class name for form elements whose values should be included in the AJAX request.

Example
<input type="text" name="username" class="user-form" value="john"> <input type="password" name="password" class="user-form" value="secret"> <pipe id="loginPipe" form-class="user-form" ajax="login.php" insert="loginResult">Login</pipe>
Login

event

Specifies which events should trigger the element's action. Used with the "mouse" class.

Example
<div id="hoverDiv" class="mouse" event="mouseover;mouseleave" ajax="hover-data.json" insert="hoverResult">Hover over me</div>
Hover over me

options

Creates options for a select element using key:value pairs.

Example
<select id="countrySelect" options="USA:us;Canada:ca;Mexico:mx"></select>

file-order and file-index

Cycles through a list of files for AJAX requests.

Example

Sets the delay in milliseconds for timed elements.

Example

Classes

download

Enables file downloading when clicked.

Example
<button id="downloadReport" class="download" file="report.pdf" directory="/reports/">Download Report</button>

redirect

Redirects to the URL specified in the ajax attribute.

Example
<pipe id="goToPage" ajax="products.html" class="redirect" query="category:electronics;">View Electronics</pipe>
View Electronics

modala-multi-last and modala-multi-first

Creates multi-ajax calls that insert content while removing either the last or first existing content.

Example
<pipe id="addMessage" ajax="message.json:chatBox:5" class="modala-multi-last">Add Message</pipe> <div id="chatBox"></div>
Message 1: Hello there!
Message 2: How are you?
Message 3: What's new?

time-active and time-inactive

Controls whether timed elements are active or inactive.

Example

disabled

Disables a tag from functioning.

Example

json

Indicates that the response should be treated as JSON.

Example
<pipe id="jsonPipe" ajax="data.json" insert="jsonResult" class="json">Load JSON</pipe>

strict-json

Returns only JSON to the full page as response. Errors if the response cannot be parsed as JSON.

Example
<pipe id="apiCall" ajax="api/data" class="strict-json">Load API Data</pipe>

plain-text

Returns plain text to the insertion point.

Example

plain-html

Returns content as true HTML.

Example

Advanced Components

Columns Component

The columns component creates responsive multi-column layouts with dynamic content loading.

Basic Usage
<columns id="threeColLayout" count="3" percents="25,50,25" height="500px" pages="sidebar.html;main.html;widgets.html"></columns>
API Usage
// Refresh a specific column window.columnsComponent.refreshColumn('threeColLayout', 1); // Update column content directly window.columnsComponent.updateColumnContent('threeColLayout', 0, '<h2>New Content</h2><p>Updated sidebar content</p>'); // Load a new page into a column window.columnsComponent.loadColumnPage('threeColLayout', 2, 'new-widgets.html');

Refresh Component

The refresh component provides functionality to refresh content in specific targets or reload the entire page.

Basic Usage
<!-- Basic refresh button --> <refresh id="refreshBtn" target="dataContainer:data.json">Refresh Data</refresh> <!-- Auto-refresh with interval (in seconds) --> <refresh id="autoRefresh" target="liveData:api/live.json" interval="30">Auto Refresh (30s)</refresh> <!-- Refresh multiple targets --> <refresh id="refreshAll" target="header:header.html;content:content.json;footer:footer.html">Refresh All</refresh> <!-- Refresh the entire page --> <refresh id="reloadPage" target="_page">Reload Page</refresh>
API Usage
// Refresh a specific target window.refreshComponent.refreshTarget('dataContainer', 'data.json'); // Refresh multiple targets window.refreshComponent.refreshTargets('header:header.html;content:content.json');

Best Practices

Performance Optimization

Follow these guidelines to ensure optimal performance with DomPipe.js:

  • Use time-inactive for timed elements that aren't currently visible
  • Avoid excessive nesting of AJAX calls
  • Use delay values of at least 500ms for timed elements
  • Consider using lazy-load with CSV components when dealing with large datasets

Security Considerations

Keep these security practices in mind:

  • DomPipe.js automatically generates a Content Security Policy with nonces for scripts and styles
  • Always validate and sanitize data on the server side
  • Use plain-text instead of plain-html when displaying user-generated content

Debugging Tips

When troubleshooting DomPipe.js:

  • Check that all elements have unique id attributes
  • Use strict-json to ensure proper JSON formatting in responses
  • For checkout components, use validate="true" to test without processing actual orders
  • Check the browser console for any error messages
